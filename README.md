# Aqui está a ideia do meu projeto:

## Quiz informativo sobre as mudanças climáticas

> **Objetivo:**
Informar e conscientizar as pessoas sobre as causas e as consequências das mudanças climáticas

>**Como funcionará:**
>> - 1: Antes do quiz começar, haverá uma breve apresentação sobre o tema das mudanças climáticas, deixando claro o que é esse fenômeno.
>> - 2: Quando o quiz começar, serão apresentadas perguntas com alternativas de respostas. Após cada resposta dada pelo usuário, serão dadas explicações completas sobre a resposta correta, de modo que o usuário realmente entenda o porquê daquela resposta.
>> - 3: Além disso, algumas curiosidades poderão ser apresentadas no intervalo entre duas perguntas.

>**Por que essa escolha?**
>> Para espalhar conhecimentos sobre as mudanças climáticas de maneira leve e divertida.
